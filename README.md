# Bot PMERJ V12
Bot completo para Railway integrado ao Centro de Gestão V12.

Comandos pessoais: /perfil /verificar /registro
Comandos restritos: /painel /auditoria /sincronizar /centro /portal

/centro publica o painel operacional e ele se atualiza automaticamente.
/portal publica o painel público com as duas imagens configuradas no site.
